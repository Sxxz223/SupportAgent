# Liberty 4 NC app connection

## App does not detect the earbuds

First confirm that Liberty 4 NC is paired in the device Bluetooth settings. If pairing is unsuccessful, reset and pair the earbuds using the official procedure before checking the soundcore app again. Try another phone or tablet if the connection problem persists.
